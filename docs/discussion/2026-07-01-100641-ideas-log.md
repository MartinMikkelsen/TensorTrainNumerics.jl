Paper details that matter for design:

- The basic single-scale construction uses Chebyshev-Lobatto interpolation cores. It is stable and needs only function values plus reusable interpolation cores, but its ranks are tied to the polynomial degree.
- The rank-revealing construction truncates on the fly and targets the true numerical rank rather than building a large object and compressing afterward.
- Sparse interpolation replaces dense Chebyshev interpolation matrices with local angular Lagrange interpolation, reducing cost when the polynomial degree is large.
- The multiscale construction uses "dangerous" dyadic intervals to defer interpolation near singularities or sharp features.
- The inverse construction maps a QTT back to multiresolution Chebyshev-Lobatto samples, suggesting a useful hybrid representation for pointwise nonlinear operations.
- The multivariate section distinguishes interleaved and serial ordering in a way that aligns with TensorTrainNumerics' `QTTvector` metadata, but the installed package currently returns fused cores for multivariate functions.

Build a first-class interpolative QTT API in TensorTrainNumerics. The first phase should wrap `InterpolativeQTT` robustly and return `QTTvector` directly, preserving domain, method, degree, tolerance, ordering, and diagnostics. The second phase should expose sparse/adaptive/multiscale choices and inversion. The third phase can consider native serial/interleaved core construction if fused conversion and reorder become a bottleneck.

Clarification from user: the user is not primarily asking about software implementation. They want an idea for a paper based on Lindsey's interpolative QTT construction, especially the idea that QTT objects can be built from interpolation/function evaluations.

Reframed paper-level direction:

The interesting contribution is to combine the 2012 global space-time QTT parabolic solver with Lindsey's multiscale interpolative construction. The older global solver assumes the full space-time solution has bounded QTT ranks; Lindsey gives a constructive and adaptive way to build, inspect, and invert QTTs through multiresolution interpolation. This suggests a paper around "interpolative space-time QTT solvers" rather than around implementation.

The strongest paper idea is a hybrid method: solve global space-time PDE systems in QTT format, but use the interpolative/multiresolution grid view to construct initial guesses, forcing terms, coefficients, nonlinear residuals, and adaptive dangerous regions. This may make nonlinear or nonsmooth parabolic problems more tractable than a pure QTT linear algebra approach.

User asked what Lindsey's method is applied to, whether Crank-Nicholson remains appropriate, and which nonlinear equations are realistic in space-time.

Clarified answer:

- Lindsey's method should be applied to the representation and construction of space-time functions: initial/terminal data, coefficients, source terms, guesses, the full solution `Y(t,x)`, and especially nonlinear residual terms `N(Y)`.
- It is not primarily a replacement for the linear Crank-Nicholson block operator. Crank-Nicholson can remain the finite-difference time discretization, producing a global nonlinear residual for semilinear equations.
- The paper-level idea is to use Lindsey's invertible QTT/interpolation viewpoint to evaluate nonlinearities on multiresolution interpolation grids, then reconstruct/compress the result as a QTT.
- Conservative route: global Crank-Nicholson + Picard/Newton outer iterations in QTT.
- More ambitious route: replace Crank-Nicholson with a fully interpolative space-time collocation method, using Lindsey-style grids in time and space.
- Best first nonlinear examples: Allen-Cahn, Fisher-KPP, semilinear reaction-diffusion, viscous Burgers at moderate viscosity, nonlinear Fokker-Planck/McKean-Vlasov, and eventually HJB/Feynman-Kac-type nonlinear equations.

User pointed to arXiv:1908.01533 and noted that the broad nonlinear/HJB tensor idea is already taken.

Checked attached paper:

- Dolgov, Kalise, and Kunisch, "Tensor Decomposition Methods for High-dimensional Hamilton-Jacobi-Bellman Equations", arXiv:1908.01533.
- The paper solves high-dimensional fully nonlinear stationary HJB equations using TT approximation of the value function and a Newton-like / policy iteration.
- It explicitly uses Allen-Cahn and Fokker-Planck dynamics as high-dimensional optimal feedback control examples.
- Therefore a paper pitched as "TT for nonlinear HJB" or "TT for Allen-Cahn/Fokker-Planck control" is not a good novelty claim.

Revised pivot:

The strongest remaining direction is not HJB/control. It is an adaptive multiscale space-time QTT collocation method for direct time-dependent parabolic PDEs. Lindsey's method should become the space-time discretization/adaptivity mechanism itself, not just a way to build initial tensors. Crank-Nicholson can remain a baseline or a preconditioner, but the paper should not present CN as the central novelty.

Potential differentiators:

- Direct evolution PDEs rather than stationary HJB value functions.
- Space-time all-at-once representation rather than policy iteration over a stationary tensor.
- Multiresolution dangerous space-time boxes for nonsmooth data, moving fronts, boundary layers, and nonlinear residuals.
- Lindsey-style interpolation/inversion used to evaluate nonlinearities and adapt the representation.
- Avoid overlap with QTT DLRA by emphasizing all-at-once space-time collocation/implicit residual solves rather than time stepping on a low-rank manifold.

User asked whether the intended method is the same space-time block solver but replacing Crank-Nicholson by Lindsey's method to build the next time point.

Clarified distinction:

- Lindsey's method is not a time integrator. It does not replace Crank-Nicholson as a formula for advancing `u_k -> u_{k+1}`.
- If used to build the next time point one step at a time, the method becomes ordinary time stepping with an interpolative QTT compressor, and it loses the main global-in-time advantage.
- The more novel direction is all-at-once space-time interpolation/collocation: represent the entire `u(t,x)` as an interpolative QTT and enforce the PDE residual at multiscale interpolation/collocation points.
- Crank-Nicholson can still be used as a baseline, preconditioner, or residual discretization, but the proposed paper should make Lindsey's method act on the whole space-time function, not on each next slice.

User noted that if Lindsey's method needs a function that can be built as a QTT, then the framework must explain what this function is when the PDE solution is unknown.

Clarified answer:

- For known objects, the function is literal: initial data, boundary data, forcing, coefficients, potentials, payoffs, manufactured solutions, low-fidelity guesses.
- For the unknown solution, Lindsey is not an oracle. The method treats the multiresolution interpolation values or QTT cores as unknowns and solves for them by enforcing the PDE residual.
- In an iterative method, each current iterate `U^m` is already an evaluable function, so nonlinear objects like `N(U^m)` can be reconstructed by the interpolative QTT map.
- Thus the framework alternates between solving/updating an unknown space-time representation and using Lindsey-style interpolation as the compression/reconstruction/evaluation operator for known functions generated by the current iterate.

Experiment implemented:

- Added `examples/global_picard_allen_cahn2d.jl`.
- Equation: 2D Allen-Cahn on `(0,1)^2`, `u_t = eps^2 Delta u + u - u^3`, with zero Dirichlet boundary treatment through the finite-difference interior grid.
- Split: `A = eps^2 Delta + I`, `N(u) = -u^3`.
- Uses the global Crank-Nicholson block operator for the linear Picard solve.
- Rebuilds `N(U^m)` as a 2+1D space-time QTT with `InterpolativeQTT.interpolatesinglescale`.
- Converts fused interpolative cores to time-first `SpaceTimeQTTvector` by splitting to single-bit cores and reordering from interleaved to serial.
- Local linear solver: ALS.
- Test parameters: `16 x 16` spatial grid, `16` time slices, `eps=0.04`, `T=0.10`, `max_bond=12`, `degree=4`, `8` Picard steps.
- Run result: ALS linear residuals around `1e-5`, Picard update down to `8.28e-4`, final nonlinear fixed-point residual about `1.99e-3`, final slice rank `12`, final slice min/max about `0.0259 / 0.5348`.

User asked to write the idea more formally in LaTeX, starting from a time evolution.

Formal framing:

- Start from a time-dependent PDE `partial_t u = F[u]` with initial/boundary data.
- Classical global Crank-Nicholson discretizes time and stacks all slices.
- Proposed method instead approximates `u(t,x)` directly by an interpolative space-time QTT.
- The unknown is not a list of time slices but a tensor train representing the continuous/discrete space-time function.
- Enforce the PDE residual at multiscale collocation points and adaptively refine space-time boxes where either interpolation error or PDE residual is large.
